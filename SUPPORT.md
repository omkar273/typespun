# Support

Typespun is in early development and support is provided on a best-effort basis.

Before asking for help, read the README, search open and closed issues, and try
the latest code or release that applies to your project.

- For reproducible incorrect behavior, use the bug report form.
- For API ideas and new capabilities, use the feature request form.
- For usage questions, open a blank issue prefixed with `[Question]` and include
  a minimal, sanitized example.

Include the Typespun package and version or commit, Bun or Node version,
operating system, relevant declaration, sanitized `typespun.json`, and the exact
error. Reduce the example as much as possible.

Never post credentials, `.env` contents, access tokens, private URLs, or
production configuration. Follow [SECURITY.md](SECURITY.md) for suspected
vulnerabilities.
